# Fonts used to generate images

`Geist-Regular.ttf`: Geist (the site's text font), copied from the copy that ships inside Next.js
(`next/dist/compiled/@vercel/og`). Used for the text in link preview images (`src/lib/ogCard.tsx`).
Geist is © Vercel, licensed under the SIL Open Font License 1.1.

`SourceSans3-Black.woff`: Source Sans 3 Black (the site's text font, heaviest weight, Latin), from the
`@fontsource/source-sans-3` package. Draws the "Smashy" wordmark and the S icon in link previews and
icons (`src/lib/iconArt.tsx`, round 861). Source Sans 3 is © Adobe, licensed under the SIL Open Font
License 1.1.
